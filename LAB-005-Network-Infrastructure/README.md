# LAB-005 — Network Infrastructure

> Portfólio técnico de Nycolas Borges · Segurança da Informação, Redes e Infraestrutura

**Área:** Redes · Infraestrutura · Fundamentos de segurança  
**Status atual:** CONTEÚDO EM CONSOLIDAÇÃO — adicionar topologia e testes

## 1. Objetivo
Compreender topologias, IPv4, máscara, gateway, DNS, DHCP, roteamento e diagnóstico de conectividade.

## 2. Pré-requisitos
- Cisco Packet Tracer
- Dois PCs, um switch e um roteador
- Endereçamento privado de laboratório

## 3. Procedimento passo a passo
1. Inserir dois PCs e um switch no Packet Tracer.
2. Conectar os PCs ao switch.
3. Configurar endereços IPv4 na mesma sub-rede.
4. Testar conectividade com ping.
5. Adicionar roteador e configurar gateway.
6. Criar uma segunda sub-rede e configurar interfaces/rotas.
7. Testar comunicação entre sub-redes.
8. Simular máscara incorreta, gateway incorreto e interface desligada.
9. Registrar sintoma, hipótese, teste e correção.

## 4. Conceitos e pontos de atenção
Conceitos: PAN, LAN, MAN e WAN; IP, máscara, gateway e DNS; switch versus roteador; DHCP versus IP estático; TCP versus UDP; segmentação de rede e menor privilégio.
